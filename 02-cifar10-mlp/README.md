# 02 - CIFAR-10 Image Classification using MLP

Image classification on the CIFAR-10 dataset using a Fully Connected Neural Network (Multi-Layer Perceptron).

## 📊 Summary
- **Dataset:** CIFAR-10 (60,000 32x32 color images across 10 classes)
- **Model Type:** Multi-Layer Perceptron (MLP)
- **Input Shape:** 32x32x3 (Flattened to 3072 features)
- **Epochs:** 15
- **Batch Size:** 256

## 🚀 How to Run
```bash
cd 02-cifar10-mlp
python cifar10_mlp.py
