# 01 - MNIST Digit Classification

Handwritten digit recognition built with TensorFlow and Keras using a Multi-Layer Perceptron (MLP) architecture.

## 📊 Summary
- **Dataset:** MNIST (28x28 grayscale images of digits 0-9)
- **Model Type:** Multi-Layer Perceptron (MLP)
- **Epochs:** 10
- **Batch Size:** 256
- **Test Accuracy:** 97.10%

## 🚀 How to Run
```bash
cd 01-mnist-classification
pip install -r requirements.txt
python mnist_classifier.py
```
