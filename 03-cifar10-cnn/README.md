# 03 - CIFAR-10 Image Classification using CNN

Convolutional Neural Network (CNN) implementation for classifying complex color images from the CIFAR-10 dataset.

## 📊 Summary
- **Dataset:** CIFAR-10 (32x32 color images)
- **Model Type:** Convolutional Neural Network (CNN)
- **Key Layers:** Conv2D, MaxPooling2D, Dense
- **Epochs:** 15
- **Batch Size:** 64

## 🚀 How to Run
```bash
cd 03-cifar10-cnn
python cifar10_cnn.py
